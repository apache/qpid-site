Detailed Description

Options for declaring a session transaction.

Options can be "chained" (see proton::connection_options).

Normal value semantics: copy or assign creates a separate copy of the options.

transaction_options & auto_modify_on_abort ( bool )

Unsettled API — If true, when a transaction is aborted, or a commit discharge is rejected, the client automatically dispositions any unsettled incoming deliveries (on receiver links) in this session with a modified (failed) outcome.

If false, the application must update those deliveries itself. The default is true.

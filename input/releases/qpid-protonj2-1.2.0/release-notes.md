# Qpid ProtonJ2 1.2.0 Release Notes

Proton is a high-performance, lightweight messaging library. More
about [Qpid Proton]({{site_url}}/proton/index.html).

For more information about this release, including download links and
documentation, see the [release overview](index.html).

See also the [ProtonJ2 security page]({{site_url}}/proton/security-j2.html) for issues addressed in this release.

## New features and improvements

 - [PROTON-2918](https://issues.apache.org/jira/browse/PROTON-2918) - [protonj2] Improve detection of io_uring being absent
 - [PROTON-2927](https://issues.apache.org/jira/browse/PROTON-2927) - [protonj2] Add OAUTHBEARER SASL mechanism to client and test peer

Qpid Broker-J 10.1.0 Release Notes

Qpid Broker-J is a message broker written in Java that stores, routes, and forwards messages using AMQP.

For more information about this release, including download links and documentation, see the release overview.

See also the Broker-J security page for issues addressed in this release.

New features and improvements

This release adds support for Java 25.

  • QPID-8013 - [Broker-J] Reduce footprint of AMQP 1.0 protocol objects
  • QPID-8706 - [Broker-J] Move AMQP-1.0 symbols declarations to a utility class
  • QPID-8731 - [Broker-J] Security Manager removal
  • QPID-8738 - [Broker-J] JUnit 6 migration - TlsResource should support parameter injection
  • QPID-8740 - [Broker-J] JUnit 6 migration - QpidUnitTestExtension should be stateless
  • QPID-8743 - [Broker-J] Add operation to close idle connections
  • QPID-8744 - [Broker-J] Jackson ObjectMapper instances shouldn't be created on each method call

Bugs fixed

  • QPID-8748 - [Broker-J] NPE when sorting results in broker query engine
  • QPID-8749 - [Broker-J] AMQP connections may not close while processing pending writes

Dependency updates

  • QPID-8729 - [Broker-J] Maven plugins and test dependencies updates for version 10.1.0
  • QPID-8730 - [Broker-J] Bump logback/slf4j dependencies to the version 1.6.0/2.0.18
  • QPID-8733 - [Broker-J] Bump fasterxml jackson dependencies to the version 3.2.1
  • QPID-8734 - [Broker-J] Bump asm dependencies to the version 9.10.1
  • QPID-8737 - [Broker-J] Bump jetty dependencies to the version 12.1.11
  • QPID-8741 - [Broker-J] Bump logback-db dependency to the version 1.5.32
  • QPID-8742 - [Broker-J] Bump bouncycastle dependencies to the version 1.84
  • QPID-8745 - [Broker-J] Bump caffeine dependency to the version 3.2.4
  • QPID-8746 - [Broker-J] Bump hikaricp dependency to the version 7.1.0
  • QPID-8747 - [Broker-J] Bump logback-gelf dependency to the version 6.1.2

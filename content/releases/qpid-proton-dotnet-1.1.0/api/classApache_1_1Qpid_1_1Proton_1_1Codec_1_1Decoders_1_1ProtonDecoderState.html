The configured maximum number of elements that can be decoded from an array encoded with the zero width AMQP types (Null, UInt0. ULong0, List0, Boolean_False and Boolean_True). A value of zero (the default) should be handled by the implementation as meaning that only an array of zero width types with zero elements can be decoded.

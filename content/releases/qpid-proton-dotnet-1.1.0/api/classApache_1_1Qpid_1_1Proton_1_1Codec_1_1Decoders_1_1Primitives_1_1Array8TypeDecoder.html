 Reads the given array from the bytes in the buffer but only if the type encoding of the given array matches the given Type filter. This allows the caller to effectively limit if the given array is decoded at all if the type encoding is not a match and also can act to limit an array to only a single level as the type encoding of nested arrays will not be the value type until the bottom of the array is reached. To allow all types and any array nesting the caller should pass the object Type.

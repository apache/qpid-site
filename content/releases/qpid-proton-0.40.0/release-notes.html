Qpid Proton 0.40.0 Release Notes

Proton is a high-performance, lightweight messaging library. More about Qpid Proton.

For more information about this release, including download links and documentation, see the release overview.

New features and improvements

  • PROTON-2594 - Use of HSM for crypto opterations with the private key of a TLS certificate
  • PROTON-2724 - Cannot disable building binaries in c/tools
  • PROTON-2751 - Reduce use of pn_buffer_t when not needed
  • PROTON-2752 - Use pn_string_t/pn_bytes_t instead of raw char*
  • PROTON-2753 - Split util.h to separate the C++ safe parts out of the C99 but not C++ parts
  • PROTON-2755 - [Python] Make python code and binding work with python 3.12
  • PROTON-2756 - [Python] There is no way to run python tests except by building a virtual environment
  • PROTON-2772 - [c] Add parameter safety annotations for printf format strings
  • PROTON-2773 - [c] Add various compiler diagnostic helper macros
  • PROTON-2774 - Support composite CMake builds
  • PROTON-2790 - Improve session flow control
  • PROTON-2791 - Add MSG_MORE performance boost to raw connections
  • PROTON-2813 - [Python] Make the python code pep8 clean
  • PROTON-2824 - C example broker doesn't respond well if the client tries to use transactions
  • PROTON-2838 - Remove all operations using the pn_data_t structure from the frame decode path
  • PROTON-2844 - Modernize python code
  • PROTON-2848 - [python] Add py.typed marker to officially support typing and be compliant with PEP 561
  • PROTON-2854 - Make it easier to build with AFL fuzzer manually
  • PROTON-2856 - Provide TLS support for intermediate CA certificates as trust anchors in OpenSSL
  • PROTON-2861 - Use C++ raw string now that we can
